# AUREA — ювелирный интернет-магазин

Лендинг ювелирного бренда **AUREA**: главная страница магазина с витриной украшений, категориями, бестселлерами, отзывами, подарочными картами и подпиской на рассылку.

Проект собран на **React + Vite + Tailwind CSS**, а код организован по методологии **[Feature-Sliced Design](https://feature-sliced.design/ru/)** (FSD).

🎨 Макет: **[Figma](https://www.figma.com/design/JV5ri7OrG2rdxnTSB0NLsW/Untitled?node-id=0-1&t=DOjB4GqwwTcfhXDA-1)**

## Быстрый старт

Нужен Node.js 20+.

```bash
npm install      # установить зависимости
npm run dev      # запустить dev-сервер (http://localhost:5173)
npm run build    # собрать production-версию в dist/
npm run preview  # посмотреть собранную версию локально
npm run lint     # проверить код линтером
```

### Настройка редактора (VS Code)

1. Установите расширения **Tailwind CSS IntelliSense** и **Prettier**.
2. Добавьте в `.vscode/settings.json`:

   ```json
   {
     "files.associations": { "*.css": "tailwindcss" },
     "tailwindCSS.classFunctions": ["cn"],
     "editor.defaultFormatter": "esbenp.prettier-vscode",
     "editor.formatOnSave": true
   }
   ```

   Так заработает автодополнение классов внутри `cn(...)`, а при сохранении файла код отформатируется и классы Tailwind отсортируются.

## Что на странице

Главная страница состоит из секций, которые идут сверху вниз в таком порядке. Каждая секция — отдельный виджет в `src/widgets/`.

| № | Секция | Папка | Что показывает |
| --- | --- | --- | --- |
| 1 | Шапка | `header` | Логотип, навигация, поиск, избранное, корзина со счётчиком |
| 2 | Первый экран | `hero` | «Свет, который остаётся» — заголовок, кнопка и фото кольца «Орбита» |
| 3 | Каталог | `categories` | Три категории: кольца, серьги, подвески — с количеством изделий |
| 4 | Мастерство | `craftsmanship` | «Драгоценное — в деталях»: о ручной работе и цифры (14 дней, 100%) |
| 5 | Бестселлеры | `bestsellers` | Четыре карточки товаров с бейджами, ценой и кнопкой «в избранное» |
| 6 | Промо коллекции | `collection-promo` | Коллекция «Тёплое сияние» (осень · зима 2026) на тёмном фоне |
| 7 | Преимущества | `benefits` | Пожизненный уход, бережная доставка, обмен 30 дней, персонализация |
| 8 | Отзывы | `testimonials` | «Истории, которые носят» — слайдер с цитатами покупателей |
| 9 | Подарочные карты | `gift-cards` | «Когда хочется сказать больше» — сертификаты от 10 000 ₽ |
| 10 | Рассылка | `newsletter` | «Новые истории — без лишнего шума»: e-mail и согласие с политикой |
| 11 | Подвал | `footer` | Логотип, соцсети, ссылки каталога и помощи, адрес бутика |

## Архитектура

Код разделён на **слои**. Чем ниже слой в списке, тем он проще и универсальнее.

```
src/
├── main.jsx                 → монтирует <App />
├── app/                     → точка входа приложения
│   ├── styles/index.css     → шрифты, Tailwind, дизайн-токены (@theme), базовые стили
│   └── App.jsx
├── pages/
│   └── home/                → только собирает виджеты по порядку
├── widgets/                 → крупные секции страницы
│   ├── header/
│   ├── hero/
│   ├── categories/
│   ├── craftsmanship/
│   ├── bestsellers/
│   ├── collection-promo/
│   ├── benefits/
│   ├── testimonials/
│   ├── gift-cards/
│   ├── newsletter/
│   └── footer/
├── features/                → действия пользователя
│   ├── toggle-favorite/         → сердечко «в избранное» на карточке
│   └── subscribe-newsletter/    → форма подписки
├── entities/                → бизнес-сущности
│   ├── product/             → ProductCard, моковые данные товаров
│   └── category/            → карточка категории, моковые данные
└── shared/                  → переиспользуемое, без бизнес-логики
    ├── ui/                  → Button, Container, Eyebrow, Badge, Input, Checkbox, IconButton…
    ├── assets/              → картинки, иконки
    └── lib/                 → cn() и прочие утилиты
```

### Что за что отвечает

- **`app`** — запуск приложения, глобальные стили, шрифты, провайдеры. Здесь нет вёрстки конкретных блоков.
- **`pages`** — страницы. Страница ничего не верстает сама, а просто расставляет виджеты по порядку:

  ```jsx
  export function HomePage() {
    return (
      <>
        <Header />
        <main>
          <Hero />
          <Categories />
          {/* ... */}
        </main>
        <Footer />
      </>
    )
  }
  ```

- **`widgets`** — самостоятельные секции страницы. Виджет собирается из фич, сущностей и shared-компонентов.
- **`features`** — то, что пользователь *делает*: добавляет в избранное, подписывается на рассылку. Здесь живут состояние и обработчики.
- **`entities`** — то, с чем работает магазин: товар, категория. Здесь лежат их карточки и моковые данные.
- **`shared`** — «кирпичики» без привязки к ювелирке: кнопки, инпуты, контейнер, утилиты. Их можно перенести в любой другой проект.

### Правила импортов

1. **Импортировать можно только из слоёв ниже.**
   `app → pages → widgets → features → entities → shared`

   ✅ виджет `bestsellers` использует `ProductCard` из `entities/product`
   ❌ `entities/product` импортирует что-то из `widgets`

2. **Слайсы одного слоя не знают друг о друге.**
   ❌ `widgets/hero` импортирует из `widgets/header`
   Если что-то нужно двоим — опустите это на слой ниже (обычно в `shared`).

   Когда сущности нужна фича (например, сердечко на карточке товара), сущность принимает её через проп-слот, а соединяет их виджет:

   ```jsx
   // widgets/bestsellers
   <ProductCard
     product={product}
     actionSlot={<ToggleFavoriteButton productId={product.id} />}
   />
   ```

3. **Импорт только через публичный API.** У каждого слайса есть `index.js`, который экспортирует наружу то, что можно использовать. Для путей используется алиас `@` → `src/`:

   ```js
   // ✅ так
   import { ProductCard } from '@/entities/product'
   // ❌ не так
   import { ProductCard } from '@/entities/product/ui/ProductCard'
   ```

### Как устроен слайс внутри

```
product/
├── ui/        → React-компоненты
├── model/     → данные, моки, состояние
├── lib/       → вспомогательные функции слайса
└── index.js   → публичный API
```

Создавайте только те сегменты, которые реально нужны.

## Стили и Tailwind

### Дизайн-токены

Все цвета, шрифты и размеры текста из макета описаны **один раз** в `src/app/styles/index.css` в блоке `@theme`. Tailwind сам превращает их в классы:

| Токен | Класс | Где в макете |
| --- | --- | --- |
| `--color-canvas` | `bg-canvas` | основной фон страницы |
| `--color-surface` | `bg-surface` | бежевые секции |
| `--color-ink` / `-muted` / `-subtle` | `text-ink`, `text-ink-muted`… | основной текст, описания, подписи |
| `--color-gold` / `-light` | `text-gold`, `text-gold-light` | золотые подписи и линии |
| `--color-espresso`, `--color-night` | `bg-espresso`, `bg-night` | промо коллекции, футер |
| `--font-serif`, `--font-sans` | `font-serif`, `font-sans` | заголовки / основной текст |
| `--text-display`, `--text-h2`, `--text-h3`, `--text-quote` | `text-display`, `text-h2`… | заголовки разных уровней |
| `--text-body`, `--text-small`, `--text-caption` | `text-body`, `text-small`, `text-caption` | текст и подписи капсом |

### Правила

1. **Никаких «магических» значений.** Не пишите `bg-[#1f1a17]`, используйте токен `bg-ink`. Нужен новый цвет — сначала добавьте его в `@theme`.
2. **Размер заголовка задаётся классом.** Preflight обнуляет размеры `h1`–`h6`: уровень заголовка — это семантика, размер — дизайн. Пишите `<h2 className="text-h2">`.
3. **Классы склеиваются только через `cn()`** из `@/shared/lib`. Он убирает конфликты, поэтому `<Button className="px-12">` действительно перебивает `px-8` внутри кнопки.
4. **Добавили новый `--text-*` в `@theme`** — допишите его в список в `src/shared/lib/cn.js`, иначе `tailwind-merge` примет его за цвет.
5. **Длинная повторяющаяся строка классов — это компонент**, а не `@apply`. `@apply` используется только для базовых стилей тегов.
6. **Варианты компонента описываются объектом:**

   ```js
   const variants = {
     primary: 'bg-ink text-white hover:bg-espresso',
     outline: 'border-ink text-ink hover:bg-ink hover:text-white',
   }
   ```

7. **Сначала мобилка.** Класс без префикса — мобильная версия, `md:` / `lg:` / `xl:` — шире.

## Как добавить новое

| Задача | Куда |
| --- | --- |
| Новая секция на главной | `src/widgets/<name>/` + подключить в `pages/home` |
| Новое действие пользователя (например, «добавить в корзину») | `src/features/<name>/` |
| Новая сущность (например, отзыв, коллекция) | `src/entities/<name>/` |
| Новая универсальная кнопка, поле, утилита | `src/shared/...` |
| Новый цвет, шрифт или размер текста | `@theme` в `src/app/styles/index.css` |

## Соглашения

- Папки — в `kebab-case`: `gift-cards`, `toggle-favorite`.
- Компоненты — в `PascalCase`: `ProductCard.jsx`, `IconButton.jsx`.
- Только именованные экспорты: `export function Button`, без `export default`.
- Данные товаров и категорий пока моковые и лежат в `entities/*/model`.
- Фотографии — `.jpg` / `.webp` шириной до 1600px в `src/shared/assets/images/<секция>/`.
